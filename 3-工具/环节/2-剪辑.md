# 环节 2:剪辑

- **执行者**:AI(用 配置.剪辑工具)
- **开工条件**:有状态 = 待剪 的切片(或中断超过 3 小时的"剪辑中")。
- **先读**:`1-流程/业务流程.md` §3、`2-标准/剪辑标准.md`、`3-工具/工具说明/剪辑_<配置.剪辑工具>.md`。

## 通用步骤(与剪辑工具无关)
1. 领取:`python3 3-工具/db.py set clip <ID> 剪辑中 --by AI`
2. 查信息:`python3 3-工具/db.py show clip <ID>`(起止、标题、钩子;若有 `打回原因`,本次必须针对它改)。
   - **`剪辑要求`** 是用户挑片段时写给你的话(如"开头从 xx 那句开始""不要提价格""剪短到 60 秒")。逐条照做;
     和剪辑标准冲突时以用户要求为准,但红线不变(时长 60–90 秒、不花钱、不编造内容)。做不到的那条在提交说明里写原因。
   - 有 `学习/我的偏好.md` 时读它的「看片」一节:用户最近打回的原因(如"太长""钩子弱")这次就先避开。
3. 截取源片段(多留 3 秒余量,不重编码;只保留第一条视频轨和音轨,丢掉相机附带的数据轨/缩略图轨):
   源文件:`工作区/<素材ID>/转录文件/<来源文件>`(mp4,或指向原片的链接);素材记录里填了 `原片位置` 的,用它。
   `ffmpeg -ss <起始-3s> -to <结束+3s> -i "<源文件>" -map 0:v:0 -map 0:a:0 -c copy "工作区/<素材ID>/excerpts/<ID>.mp4"`
   (`-ss` 放在 `-i` 前,`-to` 按原片时间计;HEVC 素材 `-c copy` 可能在非关键帧处开头,剪辑工具会处理,不必重编码。)
4. 按工具说明剪辑:竖屏 1080×1920 30fps、钩子先行、精剪、标题栏、金句卡、字幕。
5. 导出到 `成片/<ID>_<短标题>/<ID>_<短标题>.mp4` 和同名 `.srt`;把切片编号写进视频元数据 comment。
6. 自检(见剪辑标准 §4)。读时长:`ffprobe -v error -show_entries format=duration -of csv=p=0 <成片>`。
7. 登记:
   `python3 3-工具/db.py update clip <ID> 成片文件="<路径>" 字幕文件="<路径>" 成片时长_秒=<秒> 本地文件夹="<文件夹>" 剪辑工具=<工具> 剪辑标准版本=v1 --by AI`
8. 重剪/改了起止时,先跑 `python3 3-工具/db.py overlap <ID>`:盖到同一场录像里其他在做的片段,在提交说明里写
   "⚠️ 和 <片段ID>《标题》重叠 N 秒,两条都发会重复",让用户看片时决定。
9. 提交看片:`python3 3-工具/db.py set clip <ID> 已剪辑 --by AI --note "删了哪些句子/改了哪些字;要求 1「…」已按 … 处理;打回意见「…」已按 … 改"`
   (有剪辑要求或打回原因时,说明里必须逐条对上。)
   - 时长不在 60–90 秒,db.py 会拒绝。此时重剪:`python3 3-工具/db.py set clip <ID> 待剪 --by AI --note "时长 X 秒,重剪"`(计入重剪次数,累计 3 次自动转需人工)。

## 失败
- 同一步重试 1 次仍失败:`python3 3-工具/db.py set clip <ID> 需人工 --by AI --note "<原因>"`,继续下一条。
- 任何操作提示要**扣积分/付费**:立即停止,该条标需人工。
