# 平台操作笔记（④ browser-publisher / ⑤ content-monitor 使用）

> 平台改版后在此更新，并记 CHANGELOG。每条写明实测日期。

## 通用
- 浏览器：ego-lite（ego-browser skill）。一个发布批次用一个 TaskSpace。
- 首次打开各平台会弹浏览器权限（位置 / 通知）→ 只能用户处理，`handOff` 后等确认（建议拒绝）。
- 系统开着本机代理（127.0.0.1:7890）。**xiaohongshu.com、weixin.qq.com / qq.com 必须设为直连**（实测建议）：否则小红书创作者中心连不上、视频号封面一直「生成中」、位置被定位到国外。
- 平台会「自动填」错误信息（分区、标签、位置），每次都要检查改正。
- 验证码 / 风控提示 → 立即停止，告知用户。

## 封面尺寸（各平台实际要求）
| 平台 | 需要 |
|---|---|
| 抖音 | 竖 3:4 + 横 4:3 |
| B站 | 首页推荐 4:3 + 个人空间 16:9 |
| 视频号 | 3:4（个人主页/分享卡片） |
| 小红书 | 3:4 |

## 抖音（2026-11-19 实测）
- 上传页 `https://creator.douyin.com/creator-micro/content/upload`，上传后自动进入填写页。
- 作品描述：标题输入框 ≤30 字；简介是 contenteditable，点击后 `keyboard.insertText`。
- 话题：点「#添加话题」→ 输入词 → 从下拉选第一条（坐标点击）。
- 封面：点「选择封面」→ 弹窗内「上传封面」被提示层遮挡，需坐标点击；先竖封面，再切「设置横封面」上传；最后「完成」。
  关闭弹窗后封面框可能仍显示「选择封面」→ 需用户目视确认是否生效。
- 页面底部常驻「共创」说明浮层，遮挡部分控件。
- 位置、合集、共创不填；可见范围默认公开。
- （2026-11-21）**没有「原创」选项**，只有「自主声明」（AI生成/个人观点/转载/营销/虚构/无需添加），选了会显示在视频上 → 选「无需添加自主声明」。
- 话题：点「#添加话题」→ `keyboard.insertText(词)` → 下拉第一项在描述框下方约 (467,420)，坐标点击。
- 定时：发布设置「定时发布」→ 输入框 `input[placeholder="日期和时间"]` 全选后 `keyboard.type("YYYY-MM-DD HH:MM")` + Enter 即可；须 ≥2 小时后、14 天内。

## B站（2026-11-19 实测）
- 上传页 `https://member.bilibili.com/platform/upload/video/frame`，`input[type=file] >> nth=0` 直接 setInputFiles。
- 上传后会自动填分区和标签（常错：「体育运动」「淘宝」「报价」）→ 必须改。
- 标题 ≤80 字。分区是平铺列表：选「知识」（或「人工智能」）。
- 创作声明必选：课堂观点类选「个人观点，仅供参考」。
- 标签：输入框回车有时不生效 → 改点「推荐标签」里的同名项。
- 封面：「添加封面」→ 弹窗中 4:3（首页推荐）与 16:9（个人空间）分别选中后点「上传封面」；「完成」按钮可能在视口外。
- 投稿按钮「立即投稿」（停在它前面）。
- （2026-11-21）创作声明下拉里同时选「个人观点，仅供参考」+ 下方「内容为自制：未经作者允许，禁止转载」（= 原创）。
- 标签：「职场干货」「创业」「个人成长」「AI产品经理」等是话题专用词，回车不能自建 → 从「推荐标签」里点；推荐区换行后坐标会变，点完核对。
- 定时发布：开关在简介下方 → 日期下拉点日历 → 时间下拉的小时列需在列上滚轮再点。
- 封面弹窗：先点 4:3 区域再点左下「上传封面」，再点 16:9 区域再上传；「完成」后封面缩略图要几秒才显示。

## 视频号（2026-11-19 实测）
- `https://channels.weixin.qq.com/platform/post/create`，内容在 WUJIE shadow DOM 中，`input[type=file]` 仍可 setInputFiles。
- 位置会按代理 IP 自动填成国外城市 → 改「不显示位置」。
- 短标题 6–16 字。描述里 `#话题` 直接以文本输入即可识别。
- 封面「生成中」可能很久；生成完「发表」按钮才可点。「声明原创」由老师决定。
- （2026-11-21）走代理时封面永远「生成中」→ 设 weixin.qq.com 直连后重新上传即可。
- **小 bug**：即使「发表」已可点，「封面预览」仍可能一直显示「生成中」转圈；**直接点击那个「生成中」区域就会弹出手动上传封面**（老师实测）。不要等它转完。
- 声明原创：勾选后弹「原创权益」，需勾「我已阅读并同意《原创声明须知》」再点「声明原创」。
- 定时：选「定时」→ 点「发表时间」→ 日历下方时间框全选输入 `10:00` 回车 → 再点一次日期 → 关闭弹层，值才生效。
- 直连后位置默认填真实城市（如深圳市），仍按规则改「不显示位置」。

## 小红书（2026-11-21 实测，需直连）
- `https://creator.xiaohongshu.com/publish/publish`，`input[type=file]` 直接 setInputFiles 视频。首次打开会弹浏览器位置权限 → handOff 给老师拒绝。
- 标题：点标题框 insertText（≤20 字）。
- 正文是 ProseMirror：**逐行 insertText + press("Enter")**；一次性插入带 \n 的长文本会把光标弄乱，话题会插到句子中间。
- 话题：在正文末尾 `keyboard.type("#词")` 等 2 秒 → Enter 选第一项。第一项可能不是原词（如「#打工人」→「#打工人AI自救指南」），务必读回 `a.tiptap-topic` 核对，不对就 Backspace 删掉后坐标点下拉里的原词。
- 封面：点封面缩略图 →「编辑封面」→ 弹窗加载几秒 → `input[accept="image/png, image/jpeg, image/*"]` setInputFiles → 等「完成」可点后点击，转圈保存完弹窗才关。
- 原创声明：内容设置里的开关 → 弹窗勾「我已阅读并同意《原创声明须知》」→「声明原创」。
- 「关联活动」可能被自动关联（03 加 #求职 后自动关联了「秋招有路子」）→ 检查显示「取消关联」的项，未经老师同意一律取消。
- 定时发布：「更多设置」里的开关 → 日期框全选 type「YYYY-MM-DD HH:MM」Enter → 点空白处关闭；按钮变成「定时发布」（停在它前面）。

## 补充（2026-11-21，11.18 批次试传抖音时实测）
- **上传速度只有约 400KB/s**：成片 mp4 约 130MB 要 5 分钟。上传用压缩副本更快：`ffmpeg -c:v libx264 -preset veryfast -crf 24 -maxrate 5M -c:a aac -b:a 128k`，体积降到 3–17MB，约 30 秒传完（成片原文件不动，压缩副本放草稿区）。
- 抖音填写页：标题 `input[placeholder="填写作品标题，为作品获得更多流量"]`；简介是 `.zone-container[contenteditable="true"]`，先点它再 `keyboard.insertText`。
- 抖音话题：点「#添加话题」→ insertText(词) → 等 2.5 秒 → 下拉第一行（正则 `^#\s*\S+\n[\d.]+[亿万]?$`）坐标点击；别用整个下拉容器的中心点，会点到别的话题。
- **抖音封面上传输入框**：弹窗里「上传封面」按钮对应 `input.semi-upload-hidden-input >> nth=1`（nth=0 是「生成参考图」的 +，`.upload-btn-input` 会出错裁切框）。流程：点竖封面「选择封面」→ 上传 3:4 → 切「设置横封面」→ 同一输入框上传 4:3 → 「完成」。完成后表单里封面框仍可能显示「选择封面」，需目视确认。
- 视频号：创作者中心会跳 `login.html`，必须老师扫码登录后才能操作。

## 补充（2026-11-22，自动化发布）
- 此前各平台条目里写的「停在「定时发布/立即投稿」按钮前」，**现改为：定时模式核对无误后，点击带「定时」字样的最终按钮提交**（老师已将「待发布」设为发布授权）。核对项：处于定时模式、日期时间与排定一致、按钮文字含「定时」。
- 绝不点「立即发布 / 发表 / 立即投稿」（未处于定时模式时这些按钮是即时发布）。
- 提交后要看到成功提示，或能在平台的待发布/定时列表里看到该作品；读不到证据就标「需人工」，不要假设成功。
- 每平台每天两个时间点 10:00 / 12:00；平台要求定时须在 2 小时之后、14 天之内。
