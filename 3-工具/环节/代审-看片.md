# 代审:看片(用户打开了「AI 代审·看片」才会出现)

- **执行者**:AI,代替看片人决定通过还是打回。用 `--by AI代审`。
- **开工条件**:`db.py next` 出现 `代审-看片`。
- **先读**:`2-标准/剪辑标准.md` §4(交付前自检)。

## 逐条检查(全部满足才通过)
1. 规格:`ffprobe` 确认 1080×1920、30 帧、有音轨、时长在 60–90 秒内。
2. 抽 6 帧看版式:标题栏、金句卡、字幕不重叠、不出框;结尾没有黑帧。
3. 读字幕文件:专有名词、人名、英文术语没有明显错字;开头 3 秒是钩子句。
4. 隐私:画面或字幕里出现**其他人的脸、昵称、联系方式、学员姓名** → **不要通过也不要打回**,
   `python3 3-工具/db.py set clip <ID> 需人工 --by AI --note "AI代审:画面含他人信息,需用户决定"`,交给用户。

## 结论
- 全部满足:`python3 3-工具/db.py review <ID> 通过 --by AI代审 --reason "AI代审:<检查摘要>"`
- 有可修的问题(错字、遮挡、时长):`python3 3-工具/db.py review <ID> 打回 --by AI代审 --reason "<时间点+问题>"`
  (计入重剪次数,累计 3 次自动转需人工。)
