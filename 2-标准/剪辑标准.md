# 剪辑标准(怎么剪)

> 版本:v1(2026-11-19 起,2026-11-23 迁入本项目)。来源:早期成片经验,尚无数据验证。
> 本文件只写"剪成什么样才合格",不写用什么软件剪。

## 1. 结构
- **前 3 秒必须是钩子**:从原话里挑最冲突的一句放最前(可以从后面提上来),不要铺垫。
- 主体按"起因 → 冲突 → 结果/方法"走;结尾落在一句可截图的金句上,金句后不拖尾。
- **时长必须在 60–90 秒内**(目标约 75 秒)。原段落超出时精剪压缩,不要砍掉故事关键环节;不在范围内不得提交看片。

## 2. 精剪规则
- **删**:"听我说""这是理解吗""对"这类口水词、口吃重复(我我我、两个两个)、废弃的半句。
- **留**:承接词(然后/但是/所以)在去掉会让句子突兀时保留。
- 以完整句为单位取舍;拼接后必须能顺读。
- 停顿:不额外压缩;如有超过 0.6 秒的死停再处理。
- **粗口、学员姓名、敏感信息的处理:暂缓**(2026-11-23 老师决定,先跑通流程,之后再补规则)。

## 3. 画面与包装(竖屏 1080×1920,30 帧)
- **视频窗口**:左 -54、上 600、宽 1188、高 668(适配 16:9 的教室机位素材;换机位需重新定)。
- **标题栏**(全片常驻):两行标题,第二行用【】标出金色关键词,加一行英文副标题。**不放期号和日期**(断更或顺序乱时会破坏账号节奏感,2026-11-20 老师决定)。
- **金句卡**:全片 4–6 张,每张显示约 3–4 秒,相邻两张间隔 8–20 秒,按叙事节点切换;内容为一行小标题 + 两行主句,重点词用【】标金色;**第 0 秒放一张作为钩子,最后一张固定"划重点"**。
- **字幕**:单行,每行不超过 15 个字;位置在画面下方(上边距 1660,宽 960,高 100);识别出的错字必须校对,尤其是人名、公司名、英文术语。

## 4. 交付前自检(缺一不可)
- [ ] 抽 6 帧看版式:标题栏、金句卡、字幕不重叠、不出框。
- [ ] 字幕里的专有名词正确(ChatGPT、DeepSeek、浑水……)。
- [ ] 结尾无黑帧;标题栏和金句卡与视频等长。
- [ ] 成片规格:1080×1920、30 帧、有音轨、时长在 60–90 秒内。
- [ ] 切片编号已写入视频的元数据备注(如 `课-20261119-08`)。
- [ ] 同时导出同名字幕文件。

## 5. 交付位置与命名
- 每条成片一个文件夹:`成片根目录/<切片编号>_<标题>/`,里面有 `<切片编号>_<标题>.mp4` 和同名字幕文件。

## 6. 汇报必须写明的"自作主张"
删了哪些句子、改了哪些字、时长是否偏离目标(以及怎么处理的)。
