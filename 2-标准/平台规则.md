# 平台规则

> 这里只写"平台要求什么、我们的规矩是什么",不写具体点哪里(点击步骤属于工具层,见 `3-工具/平台操作笔记_原样存档.md`)。
> 目前**只启用抖音**,其他平台的规则先存档,开通时再启用。

## 1. 所有平台通用
- **只定时发布,绝不"立即发布"。** 提交前必须核对:处于定时模式、日期时间正确。不满足就不提交,标"需人工"。
- **授权**:发布记录被用户改成"待发布",才算授权发布。
- 定时要求:**须在当前时间 2 小时之后、14 天之内**。
- 每个平台每天两个时间点:**10:00 和 12:00**(北京时间);已被占用的时间点自动跳过;用户手填的未来时间原样尊重;14 天内没有空位则标"需人工"。
- 同一账号两条间隔至少 30 分钟。
- 平台自动填写的分区、标签、位置、关联活动,都要检查并改正;关联活动未经用户同意一律取消。
- 不导流、不改账号资料、不关注或私信他人、不删除作品。
- 遇到登录、验证码、风控、权限弹窗:先告知用户,等用户处理,不代填账号密码。
- 提交后必须看到成功提示,或在平台的"待发布/定时"列表里看到该作品,才算成功;读不到证据一律标"需人工"。

## 2. 抖音(启用)
| 项目 | 规则 |
|---|---|
| 标题 | 不超过 30 字,冲突放前 10 字 |
| 简介 | 标题即作品描述首句,可再补 1 句 |
| 话题/标签 | 3–5 个:1 个大词 + 2–3 个垂类词 + 1 个内容词 |
| 封面 | 竖 3:4 + 横 4:3 各一张 |
| 自主声明 | 抖音没有"原创"选项,选"无需添加自主声明"(选了其他项会显示在视频上) |
| 位置、合集、共创 | 不填 |
| 可见范围 | 公开(默认) |
| 定时 | 须在 2 小时之后、14 天之内 |
| 发布时间点 | 每天 10:00、12:00 |

## 3. 暂缓的平台(规则存档,待开通时启用)
| 平台 | 要点 |
|---|---|
| 小红书 | 标题不超过 20 字,可带 1 个 emoji;简介 200–400 字笔记体(痛点开头 → 分点干货 → 结尾抛问题);标签 5–8 个;封面 3:4,决定点击,优先级最高;需检查并取消自动关联的活动 |
| 视频号 | 描述不超过 60 字;短标题 6–16 字;标签 2–3 个;封面 3:4;位置选"不显示位置";"声明原创"由老师决定 |
| B站 | 标题不超过 40 字,可加【AI产品经理课】前缀;简介 100–300 字;标签 6–10 个;分区选"知识";创作声明选"个人观点,仅供参考"或"自制";封面 4:3 + 16:9 |
