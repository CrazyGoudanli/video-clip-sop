# 封面标准

> 版本:v1.1(2026-11-20 起,2026-11-23 迁入本项目)。原名"包装标准"。标题、简介、标签、封面字的写法见《文案标准》。

## 1. 统一视觉风格(2026-11-20 老师定稿,"道具伸向镜头"风格)
- 用 AI 生图方式制作(2026-11-23 老师确认继续使用)。
- 老师近景,**把与选题相关的道具伸向镜头**作视觉钩子(例:插线板、方案册),另一只手做讲解手势。
- 深色高级办公室背景 + 暖金氛围光 + 浅景深。
- 两行粗体白字、黑描边大标题,重点词用金黄色。
- 人物必须像老师本人(不美化、不换脸)。
- 画面中**不出现**:课堂电视/投屏/学员、其他人的脸、标志、英文、**期号、日期**。

## 2. 制作方法
- 每条只设计一次:先出竖版 3:4 定稿,再以它为依据重排 4:3、16:9,几张是同一套设计。
- 参考帧:从成片里抽取视频窗口区域的画面,选 2 张正脸、有手势的做人物参考。

## 3. 验收(缺一不可)
- [ ] 图片尺寸正确。
- [ ] **标题逐字核对**:没有错字、漏字,金色落在重点词上。
- [ ] 人脸像本人。
- [ ] 没有其他人脸、标志、英文、期号、日期。

## 4. 失败处理
- 某张不合格:把问题写进提示词重出,最多重试 2 次。
- 仍不合格或生图不可用:用备用的简易模板版封面,并告知老师。
- 两种都失败:该切片标"需人工",原因写进备注,继续其他条。

## 5. 各平台尺寸
| 平台 | 需要 | 状态 |
|---|---|---|
| **抖音** | 竖 3:4(1080×1440)+ 横 4:3(1440×1080) | **当前启用** |
| 小红书 | 3:4(1080×1440),封面决定点击,优先级最高 | 暂缓 |
| 视频号 | 3:4 | 暂缓 |
| B站 | 首页推荐 4:3(1440×1080)+ 个人空间 16:9(1920×1080) | 暂缓 |

`封面/抖音_竖3x4.jpg`、`封面/抖音_横4x3.jpg`(开通其他平台时再加对应命名)。
