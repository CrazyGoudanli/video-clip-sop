# 代审:确认发布(用户打开了「AI 代审·确认发布」才会出现)

**这一步会让作品对外发布,检查要比其他代审更严。拿不准就交给用户,不要发。**

- **执行者**:AI,代替用户授权定时发布。用 `--by AI代审`。
- **开工条件**:`db.py next` 出现 `代审-发布`。
- **先读**:`2-标准/文案标准.md` §7 红线、`2-标准/平台规则.md`。

## 逐条检查(全部满足才授权)
1. 切片已经看片通过(人工或 AI代审 都算),成片文件存在。
2. 标题、简介、话题不碰文案红线:极限词、导流、点名学员或具体机构、编造数字经历、期号日期、贬损人群。
3. 竖、横封面文件都存在,标题和文案说的是同一件事。
4. 隐私:成片画面或字幕里有**其他人的脸、昵称、联系方式** → 不授权,交给用户。
5. 内容涉及敏感话题(政治、医疗建议、金融投资建议、未核实的指控)→ 不授权,交给用户。

## 结论
- 全部满足:`python3 3-工具/db.py set pub <ID> 待发布 --by AI代审 --note "AI代审:<检查摘要>"`
  之后 `6-发布` 照常只设定时、绝不立即发布;用户在定时之前仍可在工作台撤回。
- 不满足或拿不准:`python3 3-工具/db.py set pub <ID> 需人工 --by AI --note "AI代审未授权:<原因>"`。

## 结束行
`【完成】代审-发布｜授权 N 条,交给你 M 条`
