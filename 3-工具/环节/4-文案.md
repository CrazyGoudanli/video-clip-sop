# 环节 4:文案

- **执行者**:AI
- **开工条件**:看片已通过、还没有目标平台(配置.发布平台)发布草稿的切片。
- **先读**:`2-标准/文案标准.md`、`2-标准/平台规则.md`;有 `学习/我的偏好.md` 时读「确认发布」一节(用户把推荐标题改成了什么,照那个方向写)。

## 步骤
1. 读成片字幕文件全文(`show clip` 里的 `字幕文件`),确认视频里**真正兑现**的观点、故事和数字。
2. **每个目标平台分开写**(配置.发布平台 里有几个就写几份,不要一份复制给所有平台):按 平台规则 里各平台的标题字数、简介格式、话题写法,
   各写 3 个候选标题(公式各不相同、标注公式名)、简介、标签;选一个"推荐"并写理由。
3. 写 3 个封面字候选(两行,【】标金色词),各配一个道具建议。
4. 每个候选过红线和自检,不合格就重写。
5. 写 JSON(例:`<成片文件夹>/文案.json`):
   ```json
   {"clip_id": "课-20261124-03",
    "publishes": [{"平台": "抖音", "标题": "<推荐的那个>", "推荐": "A",
                   "候选标题": ["A|反常识对比|...", "B|场景钩子|...", "C|质问|..."],
                   "标题句式": "反常识对比", "简介": "...", "标签": "#AI #职场 #面试",
                   "封面类型": "人物+大字", "文案标准版本": "v1"}],
    "封面字候选": [{"文字": "别人带简历\n你要带【方案】", "道具": "方案册"}, {"文字": "...", "道具": "..."}, {"文字": "...", "道具": "..."}]}
   ```
6. 写入:`python3 3-工具/db.py add-pub <文案.json>`(已存在的草稿不会被覆盖)。

## 默认规则
用户没逐条选,就用"推荐"标题和第一个封面字。

## 结束行
`【完成】4-文案｜N 条已写草稿(默认采用推荐)` / `【失败】…`
