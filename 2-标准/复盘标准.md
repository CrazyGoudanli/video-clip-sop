# 复盘标准(课程来源专用)

> 版本:v1(2026-11-20 起,2026-11-23 迁入本项目)。
> **适用范围:来源 = 课程。** 复盘评价的是"这节课讲得怎么样",对直播、访谈、论坛不一定成立,这些来源的处理方式待补(见 §7)。

## 1. 目的
- 给老师自己看:快速知道这节课讲了什么、讲得怎么样、下次怎么改。
- 给选片环节用:章节大纲和时间点是找切片的地图。
- 不是给学员看的课程笔记,不需要复述知识点细节。

## 2. 结构(顺序固定)
| # | 部分 | 要求 |
|---|---|---|
| 1 | 一句话主线 | 不超过 40 字,这节课从哪讲到哪 |
| 2 | 总评 | 3–5 句:主线 + 整体质量 + 最大亮点 + 最大问题 |
| 3 | 章节大纲 | 按时间顺序;每段标"文件名 起–止" + 标题 + 3–8 个要点 |
| 4 | 讲得好的地方 | 3–6 条,每条指明是哪一段、好在哪 |
| 5 | 可以改进的地方 | 3–8 条,每条:问题 + 出现位置 + 具体改法 |
| 6 | 学员提问与互动 | 谁问了什么(不写学员姓名)、怎么答的、答得如何 |
| 7 | 下次课建议 | 2–4 条,可执行 |
| 8 | 评分 | 1–5 星,按 §4 |

## 3. 评价维度(写"好 / 待改进"时对照)
1. **内容价值**:有没有干货、观点是否清晰、案例是否真实具体。
2. **表达**:口头禅密度、逻辑是否连贯、金句是否完整说出(不被打断)。
3. **节奏**:等待/操作空档、跑题、某段是否拖沓或过快。
4. **互动**:提问、作业、点评是否有效。
5. **演示**:demo 是否跑通、环境是否稳定、屏幕内容是否清楚。
6. **专业与合规**:粗口、未核实的事实断言、敏感/隐私内容是否被录入。

## 4. 评分规则
| 星级 | 含义 |
|---|---|
| ⭐⭐⭐⭐⭐ | 主线清晰、干货密集、几乎无明显问题,可直接作为对外样板 |
| ⭐⭐⭐⭐ | 整体好,有 2–3 个可改进点 |
| ⭐⭐⭐ | 有价值但问题明显(节奏/表达/演示中有一项较差) |
| ⭐⭐ | 主线不清或大段无效时间 |
| ⭐ | 基本无可用内容 |

## 5. 写作规则
- **具体到段落**:所有"好 / 不好"都要带"文件名 时间点",不写空泛评价。
- **改进点要可执行**:写"怎么改",不只写"哪里不好"。
- **直说但不评判人**:对事不对人,语气像同事复盘。
- **不写学员姓名**;不复述私人通话、财务等隐私内容(只提示"XX:XX–XX:XX 有私人事务被录入,建议课间处理")。
- **忽略语音识别的幻觉**:课间、静默段出现的"请不吝点赞""字幕志愿者"、大量重复句,不当作课程内容。
- **识别错字**:引用原话时按语境纠正明显错字(如"黑水"→"浑水")。
- **长度**:正文总计约 1500–3000 字;大纲要点短句化。

## 6. 产出
- 结构化数据(复盘 + 候选切片)和一份可读的复盘文档,存在该素材的复盘文件夹里;复盘摘要、评分写入素材记录。

## 7. 其他来源
| 来源 | 处理方式 |
|---|---|
| 直播 / 访谈 / 论坛 | 待补。建议只写"内容摘要 + 候选切片",不做教学复盘(待确认)。 |
