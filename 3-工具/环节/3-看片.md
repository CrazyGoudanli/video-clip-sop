# 环节 3:看片(人工关卡)

- **执行者**:看片人(人)。**AI 不得代做看片结论。**
- **开工条件**:有状态 = 已剪辑 的切片。`data/待办.md` 或看板里会列出来。

## 看片人怎么做
1. 打开成片:`python3 3-工具/db.py show clip <ID>` 里的 `成片文件`。
2. 只看最终成品视频:画面版式正常、字幕无明显错字、声音正常、内容完整、整体能发。
3. 给结论(可以自己运行,也可以对 AI 说"<ID> 通过"/"<ID> 打回,原因 …",AI 代为录入时用 `--by 人工` 并在备注写明是用户口述):
   - 通过:`python3 3-工具/db.py review <ID> 通过 --by 人工 --reviewer <名字>`
   - 打回:`python3 3-工具/db.py review <ID> 打回 --by 人工 --reason "00:23 字幕错字;结尾拖" --reviewer <名字>`
4. 打回后切片回到"待剪",AI 下一轮会针对打回原因重剪;累计 3 次仍不通过,自动转"需人工"。

## 规则
- 时长不在 60–90 秒的成片不能"通过"(db.py 会拒绝)。
- 未通过看片的切片不会进入文案、封面、发布。
