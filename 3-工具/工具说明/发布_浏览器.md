# 发布与数据采集:浏览器自动化

> 平台"要求什么"见 `2-标准/平台规则.md`;这里写"怎么点"。完整的旧实测笔记见 `平台操作笔记_原样存档.md`。

## 前提
- 一个能保持登录状态的浏览器,由 AI 控制。当前环境:ego lite 浏览器,命令行 `ego-browser`;动手前先运行 `ego-browser skill` 读用法(脚本通过 `ego-browser nodejs` 运行)。旧环境用的是 ego lite 浏览器(`ego-browser` 技能);其他 AI 可用自己的浏览器自动化工具,只要能保持登录态。
- 平台账号只能**用户本人登录、扫码**。

## 抖音(当前启用;2026-11-21 实测)
- 上传页:`https://creator.douyin.com/creator-micro/content/upload`,上传后自动进入填写页。
- 上传速度约 400KB/s。成片较大时传压缩副本(放临时目录,成片原文件不动):
  `ffmpeg -i <成片> -c:v libx264 -preset veryfast -crf 24 -maxrate 5M -bufsize 10M -c:a aac -b:a 128k <副本>`
- 标题:`input[placeholder="填写作品标题，为作品获得更多流量"]`(≤30 字)。
- 简介:`.zone-container[contenteditable="true"]`,先点击再输入文本。
- 话题:点"#添加话题" → 输入词 → 等约 2.5 秒 → 点下拉第一行(不要点整个下拉容器中心)。
- 封面(2026-11-23 补充:坐标点击可能无效,可在页面内对"选择封面"所在的可点击容器调用 click();弹窗里传图后**必须点"完成"**,否则不生效;完成后看右侧手机预览里封面是否更新):点竖封面"选择封面" → 弹窗里"上传封面"对应 `input.semi-upload-hidden-input` 的第 2 个(nth=1)→ 上传 3:4 → 切"设置横封面" → 同一输入框上传 4:3 → "完成"。完成后表单封面框可能仍显示"选择封面",需核对是否生效。
- 自主声明:选"无需添加自主声明"。位置、合集、共创不填。
- 定时:发布设置选"定时发布" → `input[placeholder="日期和时间"]` 全选后输入 `YYYY-MM-DD HH:MM` 回车。
- 提交(2026-11-23 实测更新):**抖音在定时模式下按钮文字仍是"发布",不会出现"定时"。** 提交前核对:"发布时间"一栏选中的是"定时发布"(不是"立即发布")、时间框的值等于排定时间、两张封面都已生效。三项都满足才点"发布";任一项不确定就不点,标需人工。
- 底部常驻"共创"说明浮层会遮挡部分控件。

## B站(2026-11-25 用户确认)
- 定时开关在简介下方;打开定时后,提交按钮仍叫「立即投稿」(和抖音定时模式下仍叫「发布」同理)。
- 提交前必须核对三项:定时开关已打开、日期时间等于排定时间、两张封面(4:3、16:9)已生效。三项都满足才点「立即投稿」;任一项不确定就不点,标需人工。
- 提交后去 `https://member.bilibili.com/platform/upload-manager/article` 核对:稿件在「进行中」,这一行写着「定时发布 YYYY年MM月DD日 HH:MM」才算成功(2026-11-25 实测;列表顶部可能先显示「审核中」,要找这一行的「定时发布」字样)。
- 其余操作见 `平台操作笔记_原样存档.md` 的 B站 一节。

## 数据采集(抖音,2026-11-25 实测通过)
- 全程只读:不回复、不点赞、不删评、不关注。
- 列表:`https://creator.douyin.com/creator-micro/content/manage`,每条作品卡片上直接有:发布时间、状态(审核中/已发布)、播放、点赞、评论、分享、收藏、完播率、2秒跳出率、吸粉量。按标题文字定位卡片。
- 作品链接:点卡片标题会新开详情页 `.../work-management/work-detail/<作品ID>`;作品链接 = `https://www.douyin.com/video/<作品ID>`。回填链接用这个。
- 详情页「总览」:播放量、点赞、评论、分享、收藏、完播率、2s 跳出率、涨粉量、脱粉量,另有平台自己的"作品诊断"(可写进复盘)。
- 详情页「流量分析」:**平均播放时长**、5s 完播率、平均播放占比、点赞率/评论率/分享率/收藏率、流量来源占比、搜索关键词。
- 详情页「评论管理」:评论昵称、时间、内容、点赞数;页面上也有"回复/删除/举报"按钮,**一律不点**。
- 播放量显示为"8.07万"这类,写库前换成数字(80700);百分比写成小数(4.62% → 0.0462)。
- 用 ego-browser 时,新开的详情页需要 `task.adopt()` 后才能读;读完关闭 Agent 自己开的页面。
