# 代审:挑选(用户打开了「AI 代审·挑选」才会出现)

- **执行者**:AI,代替用户做"要不要剪"的决定。所有操作用 `--by AI代审`,备注写清理由。
- **开工条件**:`db.py next` 出现 `代审-挑选`。
- **先读**:`2-标准/选题标准.md`。

## 步骤
1. `python3 3-工具/db.py list clip --status 候选`,按素材分组看每条的标题、钩子、概要、理由、优先级。
2. 每场素材最多选 **3 条**(`配置.代审挑选上限` 有值就按它),按这个顺序挑:
   - 优先级"高"的先;同优先级里,选题类型按选题标准 §1.2 的顺序。
   - 跳过:依赖屏幕细节才能看懂的、涉及他人隐私或未核实断言的(选题标准 §1.3)。
3. 选中的:`python3 3-工具/db.py set clip <ID> 待剪 --by AI代审 --note "AI代审:<一句理由>"`
4. 没选中的:`python3 3-工具/db.py set clip <ID> 放弃 --by AI代审 --note "AI代审:<一句理由>"`。
   用户以后想剪,可以在工作台把它改回候选。

## 结束行
`【完成】代审-挑选｜选了 N 条去剪,M 条不剪(理由见备注)`
