# 选题标准(剪哪些)

> 版本:v1(2026-11-19 起,2026-11-23 迁入本项目)。来源:早期人工经验,尚无数据验证。
> 修改规则见《标准修改规则.md》。

## 1. 通用规则(所有来源适用)

### 1.1 一条切片 = 一个独立观点
- 脱离原场景也能看懂,不依赖"刚才""上面那个"。
- 能用一句话说清:"这条讲的是 ____"。说不清就不剪。
- 起止必须对齐到完整句子的边界,不从句子中间开始或结束。

### 1.2 优先级(高 → 低)
1. **真实故事 + 冲突/反转**:报价 7 万、开屏动画撑爆安装包、蹲海鲜市场数人头。
2. **反常识观点**:"学完 AI 最大的感触是别用 AI"、"提示词越精准效果越差"。
3. **职场潜规则 / 可直接拿走的技巧**:需求评审别当场拍板、让设计先验收。
4. **新概念 + 好比喻**:电子泔水、Agent 锁死 = 取钱卖手机。
5. **工具选型 / 对比结论**:不同阶段模型怎么选。

### 1.3 不剪(避雷清单)
- 纯操作演示、依赖屏幕细节才能看懂的段落(竖屏看不清)。
- 平台合规风险:开境外账户/港卡教程、批量注册账号、搬运他人内容。
- 未经核实的事实性断言(如"某公司做空美股")。
- 课间或场外的私人电话、财务/税务等隐私内容。
- 学员个人信息、以学员画面为主体的片段。

### 1.4 每场素材的数量
- 一般 5–10 条候选,按"高/中/低"排优先级;宁缺毋滥。

### 1.5 必须打的标签(供数据复盘归因)
| 字段 | 取值 |
|---|---|
| 选题类型 | 故事 / 反常识 / 职场技巧 / 概念比喻 / 工具选型 |
| 钩子类型 | 数字冲突 / 反常识断言 / 提问 / 故事开场 / 金句 |
| 时长档 | <45s / 45–75s / 75–90s / >90s |

(注:成片时长要求是 60–90 秒,见《剪辑标准》;"<45s"和">90s"只用于记录原始片段或不达标的情况。)

## 2. 按来源补充

| 来源 | 补充规则 |
|---|---|
| 课程 | 沿用上面全部规则(这些规则原本就是为课程写的)。 |
| 直播 | 待补:直播的挑片标准是否不同,等流程跑通后根据实际片段补充。 |
| 访谈 | 待补(涉及嘉宾出镜授权、言论不被断章取义,届时单独定规则)。 |
| 论坛 | 待补(涉及主办方素材权利、多位发言人,届时单独定规则)。 |

新增来源时,在这张表里加一行,不必改上面的通用规则。
