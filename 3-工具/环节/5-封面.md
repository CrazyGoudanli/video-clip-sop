# 环节 5:封面

- **执行者**:AI(按 配置.封面风格,工具见 `3-工具/工具说明/封面_AI生图.md`)
- **开工条件**:目标平台的发布草稿还缺封面候选,或用户已选竖版、还缺横版。
- **先读**:`2-标准/封面标准.md`。

封面分两步(中间插一次用户挑选)。`db.py next` 会按当前缺什么分别出「5-封面」或「人工-选封面」。

## 第一步:出三张竖版候选(不写数据库)

**何时做**:发布草稿没有「封面竖」,且 `<成片文件夹>/封面/候选/` 里还没有图片。

1. `python3 3-工具/db.py show clip <切片ID>` 取 `封面字`、`封面道具`(作为图形主体)、`成片文件`、成片所在文件夹。
2. 用 `3-工具/模板/cover_prompt.md` 出 **3 张竖版 1080×1440** 候选。文字配色完全相同;图形风格分别是:
   - 矢量扁平 → 存为 `<成片文件夹>/封面/候选/a_矢量.png`
   - 3D 立体 → `b_3D.png`
   - 极简几何 → `c_极简.png`
3. 验收:尺寸正确;**标题逐字核对**;无人物、多余文字、标志、英文、期号、日期。不合格重出,最多 2 次。
4. **不写数据库**(不 `update pub`)。
5. 结束行:`【需人工】5-封面｜<ID> 封面候选已出,等你在工作台选一张`

## 第二步:按选定竖版出横版并登记

**何时做**:用户已在工作台选了一张,db 里「封面竖」= 那张候选的路径;「封面横」为空。

1. 以选中的竖版为参考图,出横版 1440×1080(同一套设计,文字在左、图形在右):
   `zsh 3-工具/脚本/gen_cover.sh <工作目录> <提示词文件> <选中的竖版>`
2. 转成 jpg 存为 `<成片文件夹>/封面/抖音_横4x3.jpg`;竖版也转存为 `抖音_竖3x4.jpg`。
3. 登记:`python3 3-工具/db.py update pub <ID> 封面竖=<竖jpg> 封面横=<横jpg> 包装标准版本=v2 --by AI`
4. 结束行:`【完成】5-封面｜<ID> 横竖封面已齐,等你审核`

## 失败
- 生图两次仍不合格或不可用:用后备脚本 `uv run --with pillow python3 3-工具/脚本/make_covers.py <copy.json>`,并在结束行说明。
- 后备也失败:`set pub <ID> 需人工 --by AI --note "<原因>"`。

## 到此停止
草稿齐了,等用户审核。把"草稿"改"待发布"是**用户的授权**,AI 不得代做。
