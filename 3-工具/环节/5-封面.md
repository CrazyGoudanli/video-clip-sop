# 环节 5:封面

- **执行者**:AI(按 配置.封面风格,工具见 `3-工具/工具说明/封面_AI生图.md`)
- **开工条件**:目标平台的发布草稿还没有封面。
- **先读**:`2-标准/封面标准.md`。

## 步骤
1. `python3 3-工具/db.py show clip <切片ID>` 取 `封面字`、`封面道具`、`成片文件`。
2. 抽参考帧:从成片视频窗口区域抽 8 帧(`ffmpeg -i <成片> -vf "fps=1/8,crop=1080:668:0:600" ref_%02d.png`),选 2 张正脸、有手势的。
3. 按工具说明生成:先竖 3:4(1080×1440),再以它为依据出横 4:3(1440×1080)。
4. 验收:尺寸正确;**标题逐字核对**;人脸像本人;无其他人脸、标志、英文、期号、日期。不合格重出,最多 2 次。
5. 保存:`<成片文件夹>/封面/抖音_竖3x4.jpg`、`抖音_横4x3.jpg`。
6. 登记:`python3 3-工具/db.py update pub <ID>@抖音 封面竖="<路径>" 封面横="<路径>" 包装标准版本=v1.1 --by AI`

## 失败
- 生图两次仍不合格或不可用:用后备脚本 `uv run --with pillow python3 3-工具/脚本/make_covers.py <copy.json>`,并在结束行说明。
- 后备也失败:`set pub <ID> 需人工 --by AI --note "<原因>"`。

## 到此停止
草稿齐了,等用户审核。把"草稿"改"待发布"是**用户的授权**,AI 不得代做。
