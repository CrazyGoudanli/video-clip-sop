# 封面标准

> 版本:v2(2026-11-24 起)。原名"包装标准"。标题、简介、标签、封面字的写法见《文案标准》。

## 1. 统一视觉风格(2026-11-24 用户决定:"文字+图形",不用真人)
- 用 AI 生图方式制作。
- **画面不出现真人、人脸、写实人像**(AI 生成的本人像不像、表情不自然,用户决定不用)。
- 两行超粗黑体大标题,白字、重点词金黄色,带描边或投影;竖版两行字占画面高度 30% 以上。
- 配一个和标题意思直接相关的图形:矢量扁平、3D 立体或极简几何,三选一(见 `配置.封面图形风格`)。
- 深色背景 + 金色点缀,整体不超过 3 个主色。
- 画面中**不出现**:人物、其他文字、标志、英文、**期号、日期**。
- 旧的"道具伸向镜头"真人风格(v1.1)保留为可选项,模板 `cover_prompt_人物.md`,默认不用。

## 2. 制作方法
- 每条只设计一次:先出竖版 3:4 定稿,再以它为依据重排 4:3、16:9,几张是同一套设计。
- 不需要人物参考帧;`参考/封面/` 里有用户喜欢的封面时,把 `学习/封面风格.md` 的要点写进提示词。

## 3. 验收(缺一不可)
- [ ] 图片尺寸正确。
- [ ] **标题逐字核对**:没有错字、漏字,金色落在重点词上。
- [ ] 字够粗够大(手机缩略图里一眼能读)。
- [ ] 没有人物、多余文字、标志、英文、期号、日期。
- [ ] 图形和标题意思相关、不压字。

## 4. 失败处理
- 某张不合格:把问题写进提示词重出,最多重试 2 次。
- 仍不合格或生图不可用:用备用的简易模板版封面,并告知老师。
- 两种都失败:该切片标"需人工",原因写进备注,继续其他条。

## 5. 各平台尺寸
| 平台 | 需要 | 状态 |
|---|---|---|
| **抖音** | 竖 3:4(1080×1440)+ 横 4:3(1440×1080) | **当前启用** |
| 小红书 | 3:4(1080×1440),封面决定点击,优先级最高 | 暂缓 |
| 视频号 | 3:4 | 暂缓 |
| B站 | 首页推荐 4:3(1440×1080)+ 个人空间 16:9(1920×1080) | 暂缓 |

## 6. 文件命名
`封面/抖音_竖3x4.jpg`、`封面/抖音_横4x3.jpg`(开通其他平台时再加对应命名)。
