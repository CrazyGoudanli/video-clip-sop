# 环节 0:整理录像

- **执行者**:AI
- **开工条件**:`db.py next` 出现 `0-整理`(原始录像目录根部有已录完、未整理的录像)。
- **先读**:`1-流程/业务流程.md` §1。

## 步骤
1. 对每个日期 `YYYYMMDD`,先看计划(只读,不改文件):
   `python3 3-工具/脚本/organize_day.py YYYYMMDD --root <配置.原始录像目录>`
2. 执行:`python3 3-工具/脚本/organize_day.py YYYYMMDD --root <配置.原始录像目录> --run`
   - "跨天待确认"(早于 06:00 开始或跨午夜)**不处理**,写进汇报,等用户说明归属后才加 `--include "<文件名>"`。
   - "录制中""目标已存在""认不出日期"的跳过并汇报。
3. 至少 1 个文件整理成功,就登记素材(来源不确定就问用户;课程录屏默认"课程"):
   `python3 3-工具/db.py add-source --来源 课程 --日期 YYYY-MM-DD --标题 "<日期> 课程" --本地文件夹 "<原始录像目录>/YYYYMMDD/" --状态 已整理`
   同一天同来源有多场:加 `--序号 2`。

## 完成判据
- `<原始录像目录>/YYYYMMDD/转录文件/*.mp4` 存在,原片已移入 `原始文件/`;素材记录状态 = 已整理。

## 红线
- 绝不删除原始录像;不覆盖已有文件;不自动转码重压。
