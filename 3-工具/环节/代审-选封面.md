# 代审:选封面(用户打开了「AI 代审·选封面」才会出现)

- **执行者**:AI,代替用户从 `封面/候选/` 里选一张竖版。用 `--by AI代审`。
- **开工条件**:`db.py next` 出现 `代审-选封面`。
- **先读**:`2-标准/封面标准.md`。

## 步骤
1. 逐张看候选图:标题**逐字核对**、字够粗够大、没有人物和多余文字。不合格的排除。
2. 在合格的里面,优先选和 `配置.封面图形风格` 一致的那张;都不一致就选文字最清楚的。
3. 一张都不合格:`python3 3-工具/db.py set pub <ID> 需人工 --by AI --note "AI代审:候选封面都不合格,<原因>"`。
4. 选定:`python3 3-工具/db.py update pub <ID> 封面竖=<候选图路径> 备注="AI代审:选了 <文件名>,理由 <一句话>" --by AI代审`
   之后 `5-封面` 会按它出横版。

## 结束行
`【完成】代审-选封面｜N 条已选`
