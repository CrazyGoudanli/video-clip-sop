# 环节 1:转写、复盘、挑候选切片

- **执行者**:AI
- **开工条件**:有状态 = 已整理 的素材。
- **先读**:`1-流程/业务流程.md` §2、`2-标准/选题标准.md`;来源 = 课程 时再读 `2-标准/复盘标准.md`;
  有 `学习/我的偏好.md` 时也读它的「挑选」一节(用户最近选了哪些、没选哪些、常见原因),照用户的口味挑。

## 步骤
1. 转写:**由监测脚本在启动你之前直接跑好**(本机命令,不需要 AI;也避开 Codex 沙箱用不了 GPU)。
   先看 `工作区/<素材ID>/复盘/transcript/` 里每个录像都有 `.json`:有就直接用,不要重跑。
   只有缺的时候(例如你是被用户手动叫起来的)才自己跑:
   `zsh 3-工具/脚本/transcribe.sh "工作区/<素材ID>/转录文件" "工作区/<素材ID>/复盘"`
   报 "No Metal device available"(沙箱里没有 GPU)时不要重试,直接标需人工,原因写"沙箱里没法转写,请让监测脚本或在终端跑 transcribe.sh"。
   (下文的"素材文件夹"都指 `工作区/<素材ID>`。)
2. `python3 3-工具/脚本/compact.py "工作区/<素材ID>/复盘/transcript/"*.json`,通读全部 `.compact.txt`。
   静默段、课间里"请不吝点赞""字幕志愿者"等识别幻觉要忽略。
3. 来源 = 课程:按复盘标准写 `工作区/<素材ID>/复盘/课程复盘.md`。其他来源:写 `工作区/<素材ID>/复盘/内容摘要.md`(主线 + 章节大纲带时间)。
4. 按选题标准挑 5–10 条候选。用 `python3 3-工具/脚本/segs.py <transcript.json> HH:MM:SS-HH:MM:SS` 把起止对齐到句子边界。
   - **候选之间时间段不能重叠**;讲同一个故事/同一个梗的只出一条。实在两种讲法都值得,在两条的 `理由` 里都写"和 <另一条标题> 内容相近,二选一"。
   - 写入后跑 `python3 3-工具/db.py overlap <切片ID>` 抽查,报重叠就改起止后重写。
5. 写候选 JSON(例:`工作区/<素材ID>/复盘/候选.json`):
   ```json
   {"source_id": "课-20261124",
    "clips": [{"标题": "...", "开头钩子": "原话", "概要": "...", "理由": "...",
               "起始": "00:34:24", "结束": "00:35:44", "原始时长_秒": 80,
               "优先级": "高", "选题类型": "故事", "钩子类型": "数字冲突", "时效性": "常青"}]}
   ```
   另外在 `理由` 里注明"来源文件:<转录文件名>"。
6. 写入:`python3 3-工具/db.py add-clips <候选.json>`(编号自动生成,如 `课-20261124-01`)。
7. 更新素材:`python3 3-工具/db.py update source <ID> 摘要="一句话主线" 评分="⭐⭐⭐⭐" --by AI`,
   再 `python3 3-工具/db.py set source <ID> 已复盘 --by AI`。

## 到此停止
把哪些候选改成"待剪"是**用户的决定**,AI 不得代做。
