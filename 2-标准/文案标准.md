# 文案标准(标题 / 简介 / 标签 / 封面字)

> 版本:v1(2026-11-20 起,2026-11-23 迁入本项目)。尚无数据,按经验起步。
> 修改规则见《标准修改规则.md》。封面怎么画见《封面标准》。各平台具体规矩见《平台规则》。

## 1. 账号定位与语气
- **谁在说**:AI 培训老师,在真实课堂上讲 AI 产品经理、AI 工具和职场实战。
- **对谁说**:想转行或进阶的产品经理、职场新人、想用 AI 提效的上班族。
- **语气:冲突感强。** 像老师在课上"拍桌子"说的那句话,直接、带情绪、有立场,不端着、不讲官话。
- **冲突要真**:冲突必须是成片里真的讲到的观点或故事。不编数字、不编经历,不做"标题说 A、视频讲 B"的骗点击。
- 其他来源(直播、访谈、论坛)沿用同一定位;如需调整,在 §10 补充。

## 2. 冲突来源(每个标题至少命中一个)
| 代号 | 冲突来源 | 说明 |
|---|---|---|
| 对立 | 别人 vs 你、大多数人 vs 高手 | 制造"我是哪一边"的代入 |
| 反常识 | 和常识或直觉相反的结论 | "居然是这样?" |
| 损失 | 不这样做就会吃亏、错过、被淘汰 | 损失厌恶比收益更抓人 |
| 身份 | 点名一类人(产品经理、应届生、打工人) | 让目标观众觉得"在说我" |
| 悬念 | 话说一半,留信息缺口 | 必须在视频前 3 秒或结尾兑现 |
| 画面 | 一个具体、反差的场景或动作 | "进门先掏出插线板" |

## 3. 标题公式库(候选标题要标注公式名)
| 公式 | 结构 | 例子 |
|---|---|---|
| 反常识对比 | 别人 X,你要 Y | 别人面试带简历,你要带方案 |
| 场景钩子 | 某人 + 反差动作 | 投资人助理进门,先掏出插线板 |
| 身份点名 | 做 X 的,千万别 / 一定要… | 做产品经理的,面试千万别只带简历 |
| 质问 | 你凭什么… / 你说能不…吗? | 带着方案去面试,你说能不过吗? |
| 数字结果 | 具体数字 + 结果(数字必须真实) | 一次用户调研,换来一个高薪 offer |
| 揭秘 | X 不会告诉你的… | 面试官不会告诉你的加分项 |
| 金句 | 一句能截图转发的话 | 规划上劣势,行动上强势 |

记录发布数据时,"标题句式"字段填这里的公式名,数据复盘按公式分组看效果。

## 4. 抖音的文案规矩(当前唯一启用的平台)
- **标题**:不超过 30 字,冲突放在前 10 字。
- **简介**:标题即作品描述的首句,可再补充 1 句。
- **标签**:3–5 个,构成:1 个大词(#AI)+ 2–3 个垂类(#AI产品经理 #面试)+ 1 个内容词。
- **冲突强度**:最强。

其他平台的规矩(小红书、视频号、B站)已存档在《平台规则》,开通该平台时启用。

## 5. 封面字
- 两行,每行不超过 8 个字;第二行放冲突的"落点",其中 1 个词用金色强调(写成【】)。
- 可以和标题不同:封面字负责一眼抓住,标题负责补充信息。
- 封面字确定后,还要给一个能"伸向镜头"的道具建议(见《封面标准》)。

## 6. 候选规则
- 每条成片出 **3 个候选标题**,分别用不同的公式或冲突来源,并标注公式名。
- 封面字也出 3 个候选,附对应道具建议。
- 每组标一个"推荐"并用一句话说明理由。
- **没有人逐条选用时,默认采用"推荐"标题和第一个封面字。** 老师可以改选或直接改写;选择和改动都要记录,作为迭代信号。

## 7. 红线(命中就重写)
- 极限词:最、第一、唯一、绝对、100%、史上。("第一次""第一件事"这类序数词不算,可以用。)
- 导流:微信、私信领取、加群、二维码。
- 点名学员,出现具体公司或机构名(投资机构、前雇主、大厂内部信息)。
- 编造的数字、经历、结果。
- 期号、日期(断更或顺序乱会破坏节奏)。
- 贬损某类人群、地域、性别。

## 8. 自检清单(每个候选都要过)
1. 前 10 个字有没有冲突或钩子?
2. 外行看得懂吗(不用术语也能明白)?
3. 有没有具体的人、动作、场景或数字(不能全是空话)?
4. 视频里真的兑现了吗?
5. 字数在平台限制内吗?
6. 有没有碰到红线?

## 9. 样本库(数据复盘逐步补充)
- **正例**(数据好 / 老师认可):暂无,等首批发布数据。
- **反例**(数据差 / 老师否掉):暂无。
